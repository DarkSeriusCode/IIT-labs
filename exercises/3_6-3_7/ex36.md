# Упражнение 3.6

Чтобы уменьшить размер образов отредактируем `Dockerfile` для фронтенда и бекенда.

`Dockerfile` для фронтенда:
```Dockerfile
FROM node:16.0

EXPOSE 5000

WORKDIR /usr/src/app

ENV REACT_APP_BACKEND_URL=http://localhost:8080

COPY . .

RUN npm install && npm install -g serve && npm run build && \
    rm -rf node_modules && rm -rf /var/lib/apt/lists/* && apt-get clean

CMD ["serve", "-s", "-l", "5000", "build"]
```
Размеры до и после:
```
front        latest    ada655fd4a30   14 minutes ago      1.2GB
front-better   latest    9f71effa5c7a   4 days ago       1.01GB
```

Теперь для бекенда:
```Dockerfile
FROM golang:1.16.15

EXPOSE 8080

ENV PORT=8080
ENV REQUEST_ORIGIN=http://localhost:5000

WORKDIR /usr/src/app

COPY . .

RUN go build && rm -rf /var/cache/apk/*

CMD ["./server"]
```
Рамеры до и после:
```
back         latest    b20d6a300a01   6 minutes ago       1.07GB
back-better    latest    7bee18540c63   23 seconds ago   1.03GB
```
