# Упражнение 3.7

Будем использовать образы на основе alpine для уменьшения размера образов.

Для бекенда:
```Dockerfile
FROM golang:1.16.5-alpine

EXPOSE 8080

ENV PORT=8080
ENV REQUEST_ORIGIN=http://localhost:5000

WORKDIR /usr/src/app

COPY . .

RUN go build && rm -rf /usr/local/go /go /var/cache/apk/* /root/.cache

CMD ["./server"]
```

```
back-better     latest          7bee18540c63   17 minutes ago   1.03GB
back            latest          b20d6a300a01   4 days ago       1.07GB
```

Для фроненда:
```Dockerfile
FROM node:16.0-alpine

EXPOSE 5000

WORKDIR /usr/src/app

ENV REACT_APP_BACKEND_URL=http://localhost:8080

COPY . .

RUN npm install && npm install -g serve && npm run build && \
    rm -rf node_modules && rm -rf /var/cache/apk/* /root/.cache

CMD ["serve", "-s", "-l", "5000", "build"]
```
