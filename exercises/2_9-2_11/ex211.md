# Упражнение 2.11

Допустим у нас есть проект на Haskell, который использует `make` и строко определённую версию `GHC`.
Напишем контейнер со средой разработки для этого проекта.

Начнём с `Dockerfile`:
```Dockerfile
FROM haskell:9.12.2

WORKDIR /usr/src/app

RUN apt-get update
RUN apt-get install make
```

Теперь напишем `docker-compose.yml`:
```yaml
services:
  haskell-dev-env:
    build: .
    command: make
    volumes:
      - ./project/:/usr/src/app
```

И если мы попробуем собрать проект, то всё получится и в папке с проектом мы получим скомпилированную программу.
