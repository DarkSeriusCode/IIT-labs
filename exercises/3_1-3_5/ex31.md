# Упражнение 3.1

Для этого упражнения нужно настроить CI/CD пайплайн, чтобы при коммите автоматически собирался 
Docker образ, пушился в хаб, а затем сервер автоматически подхватывал новый образ и перезапускал 
приложение.

Для этого создадим репозиторий (https://github.com/DarkSeriusCode/workflow-test)

И уже в нём напишем следующуу конфигурацию для Github Actions:
`main.yml`:
```yaml
on:
  push:
    branches:
      - main

jobs:
  publish-docker-hub:
    name: Publish image to Docker Hub
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v2
      - name: Login to Docker Hub
        uses: docker/login-action@v1
        with:
          username: ${{ secrets.DOCKERHUB_USERNAME }}
          password: ${{ secrets.DOCKERHUB_TOKEN }}
      - name: Build and push
        uses: docker/build-push-action@v2
        with:
          push: true
          tags: rustykrabik/express-app
```

Далее запустим сервер через Compose, используя:
```yaml
services:
  server:
    image: rustykrabik/express-app
    ports:
      - 8080:8080
    container_name: server

  watchtower:
    image: containrrr/watchtower
    environment:
      - WATCHTOWER_POLL_INTERVAL=60
    volumes:
      - /var/run/docker.sock:/var/run/docker.sock
    container_name: watchtower
    command: ["server"]
```

Теперь при пуше новых изменений в репозиторий будет автоматически собран Docker образ и обнолён на 
сервере.
