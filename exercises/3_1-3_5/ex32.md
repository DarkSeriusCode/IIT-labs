# Упражнение 3.2

Добавим к нашему приложению автоматический деплой на render.

Мы изменим конфигурацию так, чтобы при пуше собирался докер образ, заливался на докер хаб, 
а затем уже деплоился на render
```yaml
on:
  push:
    branches:
      - main

jobs:
    publish-docker-hub:
      name: Pushing Docker image
      runs-on: ubuntu-latest
      steps:
        - uses: actions/checkout@v2
        - name: Login
          uses: docker/login-action@v1
          with:
            username: ${{ secrets.DOCKERHUB_USERNAME }}
            password: ${{ secrets.DOCKERHUB_TOKEN }}
        - name: Build and push
          uses: docker/build-push-action@v2
          with:
            push: true
            tags: rustykrabik/rserver
    deploy:
      needs: publish-docker-hub
      runs-on: ubuntu-latest
      steps:
        - name: Deploy to production
          uses: johnbeynon/render-deploy-action@v0.0.8
          with:
            service-id: ${{ secrets.MY_RENDER_SERVICE_ID }}
            api-key: ${{ secrets.MY_RENDER_API_KEY }}
            wait-for-success: true
```

Теперь при пуше нового коммита, наше приложение автоматически деплоится на render
Ссылка: https://rserver-iqyp.onrender.com/
