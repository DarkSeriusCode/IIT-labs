# Упражнение 3.4

Улучшим скрипт сборки докер образов, реализуя DinD.

Для начала подправим скрипт, чтобы он логинился используя данные об аккаунте, записанные в ENV
```bash
#! /bin/sh

GIT_REPO=$1
DOCKER_TAG=$2

if [ -z "$GIT_REPO" ] || [ -z "$DOCKER_TAG" ]; then
    echo "You must provide Git repo and Docker tag to build with!"
    exit 1
fi

git clone "https://github.com/$GIT_REPO" ./tmp
cd tmp
docker build . -t "$DOCKER_TAG"
docker login -u "$DOCKER_USER" -p "$DOCKER_PWD"
docker push "$DOCKER_TAG"
rm -rf tmp
```

Теперь напишем наш `builder`, раелизующий DinD
`Dockerfile`:
```Dockerfile
FROM docker:latest
WORKDIR /usr/src/dir

COPY . .

RUN chmod +x builder.sh

ENTRYPOINT ["./builder.sh"]
```

Проверим работоспособность:
```
docker run -v /var/run/docker.sock:/var/run/docker.sock -e DOCKER_USER=rustykrabik -e DOCKER_PWD=<secret ^_^> builder mluukkai/express-app rustykrabik/express-app
```
