# Упражнение 3.3

Напишем скрипт, который принимает репозиторий на Github и тэг для докер образа, далее собирает 
образ и пушит его на докер хаб

Сам скрипт:
```bash
#! /bin/bash

GIT_REPO=$1
DOCKER_TAG=$2

if [ -z "$GIT_REPO" ] || [ -z "$DOCKER_TAG" ]; then
    echo "You must provide Git repo and Docker tag to build with!"
    exit 1
fi

git clone "https://github.com/$GIT_REPO" ./tmp
cd tmp
docker build . -t "$DOCKER_TAG"
docker push "$DOCKER_TAG"
rm -rf tmp
```

Попробуем собрать что-либо
```
sudo chmod +x ./builder.sh
./builder.sh mluukkai/express_app rustykrabik/express_app
```
