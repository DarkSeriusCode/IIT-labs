# Упражнение 2.2

Для того чтобы запустить контейнер `devopsdockeruh/simple-web-service` с командой `server` можно
использовать поле `command` в `docker-compose.yaml`:
```yaml
services:
  yt:
    image: devopsdockeruh/simple-web-service
    command: "server"
    ports:
      - 8080:8080
```

Теперь запустим контейнер с помощью
```
docker compose up
```
И теперь перейдя по `http://localhost:8080` мы увидим JSON от сервера!
