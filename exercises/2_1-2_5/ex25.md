# Упражнение 2.5

Для того, чтобы приложение работало правильно, нужно его масштабировать, сделать это можно с помощью
`--scale=3`. Изменять `docker-compose.yaml` не нужно, просто запустим приложение с помощью
```
docker compose up --scale compute=3
```

После этого при нажатии на кнопку, запросы идут быстрее и успевают за таймером
