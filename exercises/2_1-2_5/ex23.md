# Упражнение 2.3

Возьмём проекты `frontend` и `backend` из прошлых упражнений и запустим их вместе с помощью `docker compose`

Мы не будем изменять `Dockerfile` в каждом из проектов, т.к они прекрасно работают, наша задача - 
упростить запуск фулстек приложения

Напишем файл для `compose`
```yaml
services:
  frontend:
    build: example-frontend
    ports:
      - 5000:5000

  backend:
    build: example-backend
    ports:
      - 8080:8080
```

Результат будет схож с тем, как если бы мы просто запустили бекенд и фронтенд в разных терминалах.
