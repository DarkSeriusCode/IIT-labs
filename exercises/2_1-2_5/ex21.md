# Упражнение 2.1

Используя `Docker compose` запустим контейнер по образу `devopsdockeruh/simple-web-service`

`docker-compose.yaml`:
```yaml
services:
  server:
    image: devopsdockeruh/simple-web-service
    volumes:
      - ./text.log:/usr/src/app/text.log
```
Далее после запуска через `docker compose up` контейнер будет писать логи в файл `text.log` на хост машине

Содержимое файла `text.log`:
``````
2026-03-02 20:29:13 +0000 UTC
2026-03-02 20:29:15 +0000 UTC
2026-03-02 20:29:17 +0000 UTC
2026-03-02 20:29:19 +0000 UTC
2026-03-02 20:29:21 +0000 UTC
```
