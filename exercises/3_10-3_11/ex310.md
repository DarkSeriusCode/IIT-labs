# Упражнение 3.10

Возьмём `Dockerfile` для одного из проектов и оптимизируем его по весу и сделаем безопасней.

Исходный `Dockerfile`:
```Dockerfile
FROM rust:alpine3.21
WORKDIR /usr/src/app

COPY . .

RUN apk add g++
RUN cargo build --release -j12

ENTRYPOINT ["./target/release/rusty_oge-cli"]
```

Оптимизированный `Dockerfile`:
```Dockerfile
FROM rust:alpine3.21 AS build-stage
WORKDIR /usr/src/app

COPY . .

RUN apk add g++
RUN cargo build --release -j12 --all

FROM scratch
WORKDIR /usr/src/app

COPY --from=build-stage /usr/src/app/target/release/rusty_oge-cli .

ENTRYPOINT ["./rusty_oge-cli"]
```
