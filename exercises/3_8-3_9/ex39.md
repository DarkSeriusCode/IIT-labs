# Упражнение 3.9

Перепишем `Dockerfile` для бекенда так, чтобы ониспользовал многоэтапную сборку.

`Dockerfile`:
```Dockerfile
FROM golang:1.16.5-alpine AS build-stage

EXPOSE 8080

ENV PORT=8080
ENV REQUEST_ORIGIN=http://localhost:5000

WORKDIR /usr/src/app

COPY . .

RUN go build && rm -rf /usr/local/go /go /var/cache/apk/* /root/.cache

FROM scratch

WORKDIR /usr/src/app

COPY --from=build-stage /usr/src/app/server .

CMD ["./server"]
```

Посмотрим размер образа с помощью `docker images`

