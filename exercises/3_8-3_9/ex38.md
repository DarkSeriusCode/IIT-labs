# Упражнение 3.8

Перепишем `Dockerfile` для фронтенда так, чтобы ониспользовал многоэтапную сборку.

`Dockerfile`:
```Dockerfile
FROM node:16.0-alpine AS build-stage

EXPOSE 5000

WORKDIR /usr/src/app

ENV REACT_APP_BACKEND_URL=http://localhost:8080

COPY . .

RUN npm install && npm run build && \
    rm -rf node_modules && rm -rf /var/cache/apk/* /root/.cache


FROM node:16.0-alpine

WORKDIR /usr/src/app

COPY --from=build-stage /usr/src/app/build .

RUN npm install -g serve

CMD ["serve", "-s", "-l", "5000", "."]
```
