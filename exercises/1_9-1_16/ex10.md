# Упражнение 1.10

Запустим контейнер `devopsdockeruh/simple-web-service`, который запустим сервер на порту 8080.
Далее сопоставим порт 8080в контейнере с портом на хост машине, для примера возьмём порт 6969
```
sudo docker run -d -p 6969:8080 devopsdockeruh/simple-web-service server
```

Теперь откроем в браузере `http://localhost:6969` и получим JSON от контейнера
```json
{"message":"You connected to the following path: /","path":"/"}
```
