# Упражнение 1.16

Возбмём проект backend из упражнения 1.13 и захостим его на сервере `Render`.

Соберём образ используя этот `Dockerfile`
```Dockerfile
FROM golang:1.16.15

EXPOSE 8080

ENV PORT=8080

WORKDIR /usr/src/app

COPY . .

RUN go build

CMD ["./server"]
```
```
docker build . -t backend
```
Далее запушим его на `DockerHub`, чтобы можно было захостить на сервере
```
docker tag backend rustykrabik/server
docker push rustykrabik/server
```

Теперь мы можем спокойно захостить. Серевр доступен по ссылке: `https://server-yrx7.onrender.com`
