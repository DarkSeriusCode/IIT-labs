# Упражнение 1.15

Возьмём мой проект на C и обернём его в контейнер.
```
git clone https://github.com/DarkSeriusCode/simple-snake-ncurses
```

Теперь напишем Dockerfile, в README сказано, что необходим `ncurses, make, gcc`
```Dockerfile
FROM ubuntu:22.04

WORKDIR /usr/src/app

COPY . .

RUN apt-get update
RUN apt-get install -y gcc make libncurses5-dev libncursesw5-dev

RUN make

CMD ["./snake"]
```

Соберём образ с помощью
```
docker build . -t snake
```

Теперь запушим:
```
docker tag snake rustykrabik/snake
docker push rustykrabik/snake
```

Ссылка на образ на `DockerHub`: https://hub.docker.com/r/rustykrabik/snake
