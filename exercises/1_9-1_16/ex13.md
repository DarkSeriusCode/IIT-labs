# Упражнение 1.13

Для начала клонируем проект, который нужно обернуть в контейнер:
```
git clone https://github.com/docker-hy/material-applications
mv material-applications/example-backend .
rm -rf material-applications
```

Далее создадим `Dockerfile` в папке проекта
```
FROM golang:1.16.15

EXPOSE 8080

ENV PORT=8080

WORKDIR /usr/src/app

COPY . .

RUN go build

CMD ["./server"]
```

Создадим образ и запустим контейнер
```
sudo docker build . -t backend
sudo docker run -p 8080:8080 backend
```

Перейдём по адресу `http://localhost:8080/ping`, в ответ на это сервер отправит на `pong`)
