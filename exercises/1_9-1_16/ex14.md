# Упражнение 1.14

Отредактируем `Dockerfile` для фронтенда и бекенда, добавив в них переменные среды через `ENV`
в соответствии с `README` каждого проекта

**Frontend**:
```Dockerfile
FROM node:16.0

EXPOSE 5000

WORKDIR /usr/src/app

ENV REACT_APP_BACKEND_URL=http://localhost:8080

COPY . .

RUN npm install
RUN npm install -g serve

RUN npm run build

CMD ["serve", "-s", "-l", "5000", "build"]
```

**Backend**:
```Dockerfile
FROM golang:1.16.15

EXPOSE 8080

ENV PORT=8080
ENV REQUEST_ORIGIN=http://localhost:5000

WORKDIR /usr/src/app

COPY . .

RUN go build

CMD ["./server"]
```

Теперь пересоберём образы с новыми `Dockerfile`
```
docker build frontend -t front
docker build backend -t back
```

Запустим их в разных терминалах, чтобы видеть логи
```
docker run -p 5000:5000 front
docker run -p 8080:8080 back
```

Теперь перейдя по адресу `http://localhost:5000` и нажав на тест-кнопку, мы увидим сообщение,
что всё сделали правильно
```
Success! Great job!
``
