# Упражнение 1.12

Для начала клонируем проект, который нужно обернуть в контейнер:
```
git clone https://github.com/docker-hy/material-applications
mv material-applications/example-frontend .
rm -rf material-applications
```

Далее создадим `Dockerfile` в папке проекта
```
FROM node:16.0

EXPOSE 5000

WORKDIR /usr/src/app

COPY . .

RUN npm install
RUN npm install -g serve

RUN npm run build

CMD ["serve", "-s", "-l", "5000", "build"]
```

Создадим образ и запустим контейнер
```
docker build . -t frontend
docker run -p 5000:5000 frontend
```

После чего по адресу `http://localhost:5000` мы увидим работающее приложение, которое говорит что
`Exercise 1.12: Congratulations! You configured your ports correctly!`
