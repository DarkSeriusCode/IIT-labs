# Упражнение 2.8

Добавим прокси `nginx` в наше приложение, для этого создадим ещё один сервис в `docker-compose.yml`:
```yaml
proxy:
  image: nginx
  restart: unless-stopped
  ports:
    - 80:80
  volumes:
    - ./conf/nginx.conf:/etc/nginx/nginx.conf
```

Конфигурация с которой запускался `nginx`:
```conf
events { worker_connections 1024; }

http {
    server {
        listen 80;
        location / {
            proxy_pass http://frontend:5000/;
        }
        location /api/ {
            proxy_set_header Host $host;
            proxy_pass http://backend:8080/api;
        }
    }
}
```

Теперь все запросы на `/` маршрутизируются на `frontend:5000`, а к `/api` на `backend:8080`
